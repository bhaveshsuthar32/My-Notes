
---

## 1. Project Overview (High Level Idea)

**My Notebook** ek **digital notebook system** hoga jisme:

* Multiple **Topics / Books** honge (NodeJS, English, Flutter, History, etc.)
* Har topic ke andar **Notes** honge
* Notes ke andar:

  * Heading
  * Sub-heading
  * Content (text)
  * Images
* **Public users** sirf read kar sakte hain
* **Admin (login ke baad)** hi:

  * Notes add
  * Edit
  * Delete
  * Publish / Unpublish kar sakta hai

---

## 2. User Roles (Bahut Important)

### 1️⃣ Guest / Client (Without Login)

* Home page dekh sakta hai
* Topics ki list dekh sakta hai
* Topic ke andar notes read kar sakta hai
* Search kar sakta hai (topic / note wise)
* **Koi change nahi kar sakta**

### 2️⃣ Admin (Login Required)

* Login / Logout
* New topic create kar sakta hai
* Topic edit / delete kar sakta hai
* Notes create, update, delete
* Images upload kar sakta hai
* Notes ko draft / published kar sakta hai

---

## 3. Core Modules (Kya-kya Banana Hai)

### 🔹 1. Authentication Module

* Admin Login
* JWT based authentication
* Protected routes
* Role based access (sirf admin modify kare)

---

### 🔹 2. Topic / Book Module

Har topic ek **Notebook / Book** ki tarah hoga

**Topic ke fields:**

* Topic Name (NodeJS, English, etc.)
* Description
* Cover Image
* Status (Active / Hidden)
* Created Date

**Admin kya karega:**

* New topic add
* Topic edit
* Topic delete

**Client kya karega:**

* Topic list dekhna
* Topic open karna

---

### 🔹 3. Notes Module (Main Part)

Har topic ke andar multiple notes honge.

**Note Structure:**

* Title (Heading)
* Sub-Title (Sub heading)
* Content (long text / paragraphs)
* Images (multiple)
* Topic ID (kis topic ka note hai)
* Status (Draft / Published)
* Created / Updated Date

**Admin Features:**

* Add new note
* Edit existing note
* Delete note
* Publish / Unpublish

**Client Features:**

* Read notes
* Scroll / pagination
* Next / Previous note

---

### 🔹 4. Notebook Style Layout (UI Concept)

* Left side: Topic list (book list)
* Right side: Notes content
* Clean reading UI (Medium / Notion style)
* Images between content
* Headings & sub-headings clearly visible
