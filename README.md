# 📒 My Notes

A **full-stack notes management application** where users can browse and read educational notes easily.  
The project includes a **Node.js backend, React web frontend, and a Flutter mobile application**.

---

## 🚀 Project Overview

**My Notes** is a learning platform where users can explore notes organized by topics.  
The application is designed for both **web and mobile users**.

Users can:

- 📚 Browse notes by topics  
- 🔍 View detailed notes and lessons  
- 📱 Access notes from web and mobile  
- 👨‍💻 Admin can manage notes and topics  

---

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/My-Notes.git
cd My-Notes
```

---

### 2️⃣ Backend Setup

```bash
cd Server
npm install
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd Client
npm install
npm run dev
```

---

### 4️⃣ Mobile App Setup

```bash
cd App/my_notebook
flutter pub get
flutter run
```
